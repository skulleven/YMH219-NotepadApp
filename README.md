# Tanıtım
C# ve WinForms kullanılarak yapılmış basit bir Not Defteri. 

# Kullanılan Teknolojiler
.NET 10, WinForms

# Kurulum
Repo'da verilen .slnx dosyasını Visual Studio 2026 (veya daha yeni) kullanarak açın ve çalıştırın.

# Temel Özellikler
Notlara istenilen isim koyulabiliyor.
Notlar silinebilir.
.txt olarak saf metin belgesine aktarılabilir.
JSON dosyası ile organize kaydedilir.
